
# SQL Scripts

This folder contains the six SQL scripts used in the Medication Adherence Analysis project.

## Scripts

1. `01_database_setup.sql` — Database creation.
2. `02_prescription_drug_join.sql` — Joining prescription and drug reference tables.
3. `03_eligible_prescriptions.sql` — Prescription eligibility filtering.
4. `04_patient_cohort_creation.sql` — Patient cohort creation.
5. `05_measurement_windows.sql` — Patient measurement period calculations.
6. `06_refill_timeline.sql` — Preparing prescription refill timelines.
